# Щоденник думок, емоцій та поведінки — PWA

Простий офлайн-щоденник для iPhone (іконка на робочому екрані, працює без інтернету, дані зберігаються тільки на вашому телефоні).

## Файли
- `index.html` — сам застосунок
- `manifest.json` — налаштування PWA (назва, іконка, колір)
- `sw.js` — service worker для офлайн-роботи
- `icon-192.png`, `icon-512.png` — іконки

## Як розмістити на GitHub Pages (безкоштовно)

1. Створіть новий репозиторій на github.com, наприклад `mood-diary` (можна приватний — це не важливо, бо GitHub Pages віддає файли публічно за посиланням, але без вашого дозволу нікому не відомим).
2. Завантажте туди всі 5 файлів із цієї теки (кнопка **Add file → Upload files** на сторінці репозиторію, або через `git push`).
3. Відкрийте **Settings → Pages** у репозиторії.
4. У розділі **Build and deployment** виберіть **Source: Deploy from a branch**, branch — **main**, папка — **/ (root)**. Збережіть.
5. Через 1–2 хвилини GitHub покаже посилання типу:
   `https://ВАШ_ЛОГІН.github.io/mood-diary/`

## Встановлення на iPhone

1. Відкрийте це посилання в **Safari** на iPhone.
2. Натисніть кнопку **Поділитися** (квадрат зі стрілкою вгору).
3. Виберіть **На екран "Домівка"** (Add to Home Screen).
4. Готово — з'явиться іконка, застосунок відкриватиметься на весь екран, без адресного рядка, і працює офлайн.

## Дані

Усі записи зберігаються локально на телефоні (localStorage), нікуди не надсилаються. Якщо очистити дані Safari/перевстановити — записи буде втрачено, тому періодично робіть експорт (CSV) як резервну копію.

## Оновлення застосунку

Якщо захочете змінити поля чи дизайн — попросіть допомогти зі змінами в `index.html`, потім повторно завантажте оновлений файл у той самий репозиторій (перезапише старий). iPhone підхопить оновлення при наступному відкритті (може знадобитись закрити застосунок повністю і відкрити знову).
